# L.M.R. — Learn. Memorize. Repeat.

Учись. Запоминай. Повторяй.

A personal offline-first iOS language learning application.

## Technology

- Swift
- SwiftUI
- SQLite / GRDB
- Swift Concurrency
- XCTest

## Project structure

- App — iOS application and interface
- Core — shared application logic
- Tests — automated tests
- .github/workflows — CI/CD

## Build

The Xcode project is generated from `project.yml` using XcodeGen.
Builds run on macOS through GitHub Actions.
